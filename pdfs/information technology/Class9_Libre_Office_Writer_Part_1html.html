Chapter 4 - Introduction to Word Processor[cite: 1]

4.1 What is a Word Processor?[cite: 1]

Word Processor: An application software that provides tools to create, edit, format, store, and print text-based documents[cite: 1].

Word Processing: The entire process of composing, editing, formatting, and printing a document using a word processor[cite: 1].

Popular Applications: LibreOffice Writer, OpenOffice Writer, WPS Office, Google Docs, MS Word, Adobe Acrobat, WordPad, Notepad[cite: 1].

Advantages of using a Word Processor[cite: 1]:

  • Easy to type, edit, and format documents for appealing presentation[cite: 1].
  • Created documents can be stored digitally for future reference[cite: 1].
  • Allows creation of professional documents using templates[cite: 1].
  • Produces error-free documents via Spelling and Grammar checks[cite: 1].
  • Password protection available against unauthorized access[cite: 1].
  • Digital documents are highly portable, shareable, and collaborative[cite: 1].

4.2 Introduction to LibreOffice Writer[cite: 1]

Writer is the word-processing component of the LibreOffice suite[cite: 1]. It saves files in the Open Document Text format with the extension .odt by default, but can export to .doc, .docx, .rtf, and .pdf[cite: 1].

Starting LibreOffice Writer: Click Start → Search 'LibreOffice' → Select LibreOffice Writer[cite: 1].

Parts of the LibreOffice Writer Window[cite: 1]:

  • Title Bar: Displays document and application name alongside window controls (Minimise, Maximise, Close)[cite: 1].
  • Menu Bar: Contains drop-down menus (File, Edit, View, Insert, Format, Styles, Table, Form, Tools, Window, Help)[cite: 1].
  • Standard Toolbar: Displays frequently used tool icons across components[cite: 1].
  • Formatting Toolbar: Context-sensitive bar that changes options based on cursor selection[cite: 1].
  • Sidebar: Vertical right-hand panel for quick access to Properties, Styles, Gallery, and Navigator[cite: 1].
  • Work Area / Workspace: Typing area equipped with a Horizontal Ruler for tabs, indents, and margins[cite: 1].
  • Status Bar: Bottom bar displaying page count, word/character count, language, and zoom slider.

4.3 Creating and Saving a Document

New Document: Press Ctrl+N or File → New → Text Document.

Save (Ctrl+S): Updates current file keeping existing name, format, and location.

Save As (Ctrl+Shift+S): Used to change filename, storage location, or file format.

AutoRecovery: Automatically saves open documents at specified time intervals to protect against sudden shutdowns.

Saving with Password:

  1. Select File → Save As.
  2. Tick the "Save with password" option.
  3. Set and confirm the password in the dialog box, then click OK.

Document Views:

  • Normal View: Default editing view.
  • Web View: Renders layout as it would appear on a web page.
  • Full Screen View (Ctrl+Shift+J): Hides toolbars for focused reading/editing.
  • Print Preview: Displays exact layout based on WYSIWYG (What You See Is What You Get).

Chapter 4 - Revision Questions & Answers

Q: Difference between Save and Save As?

A: Save (Ctrl+S) updates the file with the same name and location. Save As (Ctrl+Shift+S) is used to change the file name, storage location, or file extension.

Q: What is the purpose of the Navigator?

A: The Navigator (F5) lets the user quickly jump to any object (Headings, Tables, Images, Bookmarks) in a large document without manual scrolling.

Chapter 5 - Editing Text Using Writer

5.1 Why Editing?

Editing: The process of revising a document to remove spelling/grammar errors and enhance clarity, structure, and readability.

5.2 Selecting Text

  • Word: Double-click on the word.
  • Sentence: Triple-click on the sentence.
  • Paragraph: Click four times inside the paragraph.
  • Contiguous Text: Drag mouse OR hold Shift + Arrow keys.
  • Non-contiguous Text: Select first block, hold Ctrl, and select subsequent blocks.
  • Vertical Block: Edit → Selection Mode → Block Area.

5.3 Undo and Redo

Undo (Ctrl+Z): Reverts the previous editing action.

Redo (Ctrl+Y): Reverses the action performed by the Undo command.

5.4 Moving and Copying Text

  • Cut (Ctrl+X): Removes text to clipboard for moving.
  • Copy (Ctrl+C): Duplicates text to clipboard.
  • Paste (Ctrl+V): Inserts contents of clipboard at cursor position.
  • Paste Special (Ctrl+Shift+V): Pastes text with control over formatting retention.

5.5 Find and Replace

Access via Ctrl+F (Find Bar) or Ctrl+H (Find and Replace Dialog). Features options like Match Case and Whole words only.

5.6 Non-Printing Characters

Special layout markers (spaces, tabs, line breaks, paragraph marks) visible on screen via Ctrl+F10 or View → Formatting Marks. They do not appear in print.

5.7 Spell Check & Thesaurus

Spell Check: Red wavy line = Spelling error; Blue wavy line = Grammar error. Toggle Auto-check via Shift+F7.

Thesaurus (Ctrl+F7): Offers synonyms to replace repeated words and refine vocabulary.

Chapter 5 - Revision Questions & Answers

Q: What is the difference between Insert mode and Overtype mode?

A: In Insert mode, newly typed characters push existing text to the right. In Overtype mode, newly typed characters replace existing text. Toggle using the Insert key.

Chapter 6 - Apply Formatting Features

Formatting: Organizing document appearance (fonts, indents, colors, margins) for professional presentation. Can be applied manually or using predefined Styles.

6.1 Text & Paragraph Formatting

Clear Direct Formatting: Resets manual formatting to default using Ctrl+M.

Paragraph Alignments: Left, Center, Right, and Justified.

Indentation: Adjusting distance of paragraph blocks from left/right margins.

6.2 Text Case Transformations

Modify case options via Format → Text or cycle using shortcut Shift+F3:

  • UPPERCASE
  • lowercase
  • Sentence case
  • Capitalize Every Word
  • tOGGLE cASE

6.3 Character Positioning & Lists

Superscript (Ctrl+Shift+P): Raises text above line (e.g., x²).

Subscript (Ctrl+Shift+B): Lowers text below line (e.g., H₂O).

Lists: Unordered/Bullets (Shift+F12) and Ordered/Numbered (F12).

6.4 Page Layout Features

  • Page Break: Forces content to next page via Ctrl+Enter.
  • Header & Footer: Repeated top/bottom margins across pages for title, author, or page numbers.
  • Columns: Splits page width into multiple vertical reading sections.
  • Special Characters: Insert non-standard symbols via Insert → Special Character.
  • Images & Shapes: Add visual elements via Insert → Image / Shape or drag-and-drop.

Chapter 6 - Revision Questions & Answers

Q: Difference between Text Highlighting and Paragraph Background color?

A: Highlighting applies color strictly behind the selected characters. Paragraph Background covers the entire block area, including empty margins and indents.
